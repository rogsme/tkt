tkt reads its settings from ${XDG_CONFIG_HOME:-~/.config}/tkt/config.toml. Without
that file it runs Claude Code and OpenCode on their default models, with the
built-in stage lines.

Presets choose the agent. Each is a [presets.NAME] table:

  [presets.claude]
  harness = "claude"            # claude or opencode
  serves = ["frontier"]         # the Model: values it serves; leave out for any

  [presets.fast]
  harness = "opencode"
  model = "acme/small#max"      # leave out for the harness's default model
  serves = ["small"]

Order matters. The first preset is the default, and its tabs carry the bare
ticket id; other presets' tabs read "ACM-12 (fast)". When a prompt carries a
Model: line, tkt start picks the first preset that serves it. tkt resume
picks the first preset of the session's harness. --as NAME picks one yourself.

A Claude Code model reads model#effort, such as "opus#high". An OpenCode model
reads provider/model#variant.

Stages are the lines tkt run sends. A [stages] table overrides the built-in
ones or adds your own; {id} becomes the ticket id:

  [stages]
  address = "Use the address-pr-review skill to address the review on this branch's pull request."
  lint = "Run the linter on {id} and fix what it reports."

Three more tables tune tkt auto, the review step and the marks tkt ls sets.
These are the defaults:

  [auto]
  max_rounds = 5        # address, sync and ci runs since the plan's approval
  poll = "30s"          # how often a loop reads the forge while it waits
  max_parallel = 3      # tkt auto loops at once in a repository; 0 for no cap

  [review]
  bot_wait = "15m"      # how long a new head waits for the review bot; "0s"
                        # when no bot reviews, so review-pr runs at once

  [board]
  stale_after = "2h"    # mark an agent idle this long with no status; "0s" for never

An [agent] table sets up tkt agent's chat. model is a pi model pattern, such as
provider/id; leave it out for pi's default. extensions lists more pi extension
files to load, as absolute paths or paths that start with ~/:

  [agent]
  model = "acme/large"
  extensions = ["~/.pi/agent/extensions/acme-provider.ts"]

An unknown key is an error, so a misspelling never passes silently. tkt doctor
checks the file.

Older versions of tkt read presets and stages column files. When only those
exist, tkt stops and prints the equivalent config.toml to copy.
